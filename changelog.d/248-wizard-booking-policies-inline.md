- **The setup wizard's Booking Policies step now carries the two sections its
  own checklist reads (#248).** The default cancellation policy — refund
  rules, the non-member hold, and the cross-lodge waitlist order — and the
  group discount now show inline on the step itself, the same editors you would
  reach from Admin → Booking Policies, saving to the same place.

  Minimum night stay, date-specific cancellation periods, adult-member
  hosting, and public booking requests still live on their own screens,
  because nothing this step's checklist reads changes when you save them.
  "Open the settings for this step" above the two inline sections still takes
  you to the full hub for those four.

  Saving either section here does not tick the step off — "Mark this step
  done" is still the one action that records that a person agreed the policy
  is right.
