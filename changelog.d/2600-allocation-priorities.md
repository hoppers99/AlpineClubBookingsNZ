- **Bed-allocation preferences can now be ordered separately for each lodge
  (#2593).** Booking Officers can choose which soft preferences guide automatic
  allocation and place them in priority order, while capacity, holds, approvals,
  age separation, double-bed rules and other hard safeguards remain unchanged.

  The settings use an explicit Edit, Save and Cancel workflow. Disabling every
  preference is supported, and the separate single-night drag control remains a
  local board aid rather than a saved policy.

  Saving preferences does not move existing allocations or automatically rerun
  the planner. The new per-lodge setting starts with the historical allocation
  order, so deployment preserves existing behaviour until an officer changes it.
