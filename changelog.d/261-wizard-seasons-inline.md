- **The setup wizard's Seasons And Rates step now carries the season-window
  editor itself (#261).** It shows the same list as Admin → Seasons inline,
  beneath the step's check: pick a lodge, review its season windows, **Edit
  window** to change a name, type, dates or active state, **Activate**/
  **Deactivate**, or **Delete**. It is the same editor saving through the same
  routes, not a second copy, and Admin → Seasons is unchanged in what it does.

  **Adding a brand-new season and setting its nightly rates still happen at
  Admin → Fees → Hut Fees**, which this pane links to — a season cannot be
  created without at least one rate, and rates are set there, never on this
  page. Reactivating a dormant season that already has rates is different: it
  is real work this pane can complete on its own, and it can clear the step's
  blocked state without a trip to Fees. Whether every membership type has a
  rate is still only fixed at Fees, so a perfect save here can still leave the
  step reading amber. The pane's own text says so.

  The checklist above this pane is club-wide across every lodge, while the
  editor is scoped to one lodge at a time — the pane says so, because arriving
  from the wizard rail can land on a different lodge than the one its figures
  counted.

  Editing, reactivating, deactivating or deleting a window from inside the
  wizard makes the step's badge and detail lines catch up straight away, the
  same as every other inline editor in the wizard — saving here does not tick
  the step off; **Mark this step done** is still the one confirmation that a
  person agreed.
