- **The dashboard now tells you which lodge needs a hut leader, and counts each
  lodge's night separately (#2917).** The uncovered-nights count behind the
  **Hut Leader Assignment Required** card, the sidebar badge and the stuck-state
  tile looked at the whole club at once and reported a bare calendar date. On a
  club with more than one lodge that hid real work: a night where Lodge A had a
  leader and Lodge B did not was reported once, with both lodges' bookings and
  guests added together, and nothing said where to send anyone.

  Each lodge runs its own hut leader, so an uncovered night is now counted once
  **per lodge**, with that lodge's own booking and guest numbers, and the date is
  shown with the lodge beside it. A night with two uncovered lodges therefore
  counts as two — the true amount of work — so the number on the dashboard can
  read higher than it did before for a multi-lodge club. Club-wide counts cover
  active lodges only, matching the nightly automatic assignment, which never
  assigns for an archived lodge.

  A club with a single lodge sees no change at all: the same dates, the same
  counts and the same wording as before, with no lodge name added. The Hut
  Leaders page itself is unchanged — it has always shown just the lodge in its
  selector.
