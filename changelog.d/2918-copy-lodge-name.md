- **Booking-request screens now name the lodge you asked for, not the club's
  main one (#2918).** On a club with more than one lodge, the confirmation
  screen could thank you for a request "with" one lodge while the details
  directly underneath named a different one, and the school-request screens did
  the same. The wording now uses the lodge the request is actually for.

  Nothing changes for a club with a single lodge. The wording shown *before* a
  lodge is chosen — the short introduction at the top of each request form —
  still names the club, which is correct, because at that point no lodge has
  been picked.
