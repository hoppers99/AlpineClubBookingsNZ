# Grandfathered historical data-rewriting migrations (#2418).
#
# Recorded 2 Aug 2026, the day scripts/check-data-migration-verification.sh was
# introduced. Every name below is a migration that ALREADY SHIPPED without an
# executable verification fixture: it rewrites rows a club already had, and no
# CI job has ever run it against a real PostgreSQL holding realistic pre-state.
#
# They are listed rather than exempted by a baseline date on purpose. A date
# cutoff hides how much is uncovered; a list states it, one line per migration,
# and shrinks visibly as fixtures are written. Retro-fitting all 85 would be
# archaeology on databases that applied them months ago — the point of the gate
# is that the NEXT one cannot ship unverified.
#
# RULES
#   * This list only ever SHRINKS in normal work. Removing a name means its
#     fixture now exists (prisma/migration-verification/<name>.ts); drop
#     EXPECTED_GRANDFATHERED_COUNT in check-data-migration-verification.sh by one
#     in the same commit.
#   * ADDING a name means "this data-rewriting migration ships UNVERIFIED" and
#     needs the same justification a security waiver would, stated in the PR
#     body. The pinned count exists so an addition cannot ride in unnoticed.
#   * A name here that also has a fixture is a hard failure — the two states are
#     mutually exclusive, so the list can never drift into decoration.
#   * A name here that no longer classifies as data-rewriting is a hard failure
#     too: either the row is stale or the classifier has regressed.
#
# Blank lines and lines beginning with "#" are ignored.
